# Neon Snake

Мини-игра на одном HTML-файле: неоновый «Змейка» с поддержкой клавиатуры и свайпов. Без сборки, зависимостей и интернета.

## Запуск

Просто откройте `index.html` в браузере.

Или поднимите локальный сервер:

```bash
python3 -m http.server 8080
```

и перейдите на http://localhost:8080

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | `←` `↑` `→` `↓` или `WASD` |
| Пауза | `Space` |
| Заново | `R` |
| Свайп | на мобильных |

Рекорд сохраняется в `localStorage`.

## Что внутри

- Canvas 2D, сетка 20×20
- Плавное неоновое свечение и пульсирующая еда
- Адаптивный размер, поддержка тач-управления
- Никаких внешних ресурсов — один файл `index.html`
